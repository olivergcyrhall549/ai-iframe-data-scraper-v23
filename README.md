## Overview

AI-Powered Iframe Data Scraper is a Chrome and Firefox extension for retrieving content embedded in iframes and organizing that content as JSON with AI-assisted processing. It is intended for situations where information inside embedded page elements must be collected and cleaned up with minimal manual effort.

The extension supports browser-based scraping, structured-data workflows, and processing approaches associated with OpenAI and ChatGPT. Its straightforward interface is intended for repeatable research and data-collection tasks that require embedded content to be transformed into a usable format.

## Core Capabilities

- Retrieves information from iframe elements within web pages
- Applies AI-assisted processing to help organize extracted content
- Produces JSON output for use in later steps
- Supports both Chrome and Firefox
- Provides a simple interface for routine extraction work
- Fits browser-based web-scraping workflows
- Supports use cases involving OpenAI or ChatGPT integration concepts
- Converts embedded page content into data that can be acted on

1. Download the repository or clone it locally.
2. Add the extension to your browser:
   - **Chrome:** visit the Extensions page, enable Developer mode, and load the unpacked extension directory.
   - **Firefox:** use the add-ons or debugging tools to load the extension package in the supported manner.
3. Accept the permissions requested by the browser during the initial launch.

Once the extension is installed, access it from the browser toolbar and begin working with a page that includes iframe content.
